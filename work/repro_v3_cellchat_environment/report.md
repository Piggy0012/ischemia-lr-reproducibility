# Environment audit and tested restoration scope

The native CellChat analysis ran under R 4.6.1 on 64-bit Windows with an isolated 42-package overlay placed before the inherited decontX dependency library and the R runtime library. Independent capture found 287 effective analysis packages. The 245 inherited/runtime package versions and DESCRIPTION bytes match the earlier baseline capture; the 42 overlay packages are additions, with no inherited package version replaced. CellChat is 2.2.0.9001, with installed source commit `75253cd0c9e68410e6e721a6d3a0419a1d7e358f`. The compiled Windows package was downloaded from the third-party `blaserlab.r-universe.dev` repository. Its original binary SHA-256 and its official-source verification record are preserved.

The new [renv.lock](renv.lock) records the actual combined library, with 274 nonbase packages. The capture includes an additional renv 1.2.4 package used for lock generation; this package was absent from the model library stack. Exact versions, repository fields, build metadata, remote commits and DESCRIPTION hashes are in [package_lock.tsv](package_lock.tsv). A repository-based lock record alone does not guarantee that a later build with the same version string reproduces the original compiled artifact. Therefore the exact 42 original Windows ZIPs are separately indexed by URL and SHA-256 and retained in a release archive.

The independent Python review uses `rdata` 1.1.0 for a cross-language RDS check. Contrary to the initial concern, the immutable baseline Python lock and the staged copy already contain this pin. A current capture found the same 109 exact package pins, with no additions, removals or version changes. All five external imports and their 62 active recursive dependencies were locked and met their declared version constraints; `pip check` passed. The supplementary current lock, explicit optional `rdata` pin, empty-delta record and import/dependency audit are included. This is an audit of the actual environment, not a newly tested full Python/conda restoration.

On 11 September 2026, the offline restoration script installed all 42 archived ZIPs into a previously nonexistent library, checked the 245 inherited/runtime package versions and all 287 resulting effective versions, and loaded the native CellChat namespace from the new library. The installed commit matched the analysis. Binary SHA-256 values, inner ZIP CRCs and metadata hashes passed. The restore used no network access and fitted no scientific model. Its [audit](offline_restore_smoke_audit.json), [session record](offline_restore_smoke_sessionInfo.txt) and [execution log](offline_restore_execution.json) are archived. A complete restoration of the inherited dependencies from an empty machine, a full combined source restore through renv and restoration on another operating system were not tested.

## Suggested manuscript methods text

Native CellChat was run in R 4.6.1 using an isolated library containing 42 additional packages before the inherited analysis dependencies. We archived the effective 287-package version and provenance manifest, installed DESCRIPTION records, session information and a combined renv lock. The exact 42 Windows binary packages were retained with SHA-256 checksums. In a separate new library, offline installation of these binaries, verification of all 287 effective package versions and loading of the pinned native CellChat namespace succeeded while inheriting the original version-matched baseline. This check did not repeat model estimation or constitute a full restoration of the baseline from an empty environment.
