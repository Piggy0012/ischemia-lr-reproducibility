# Native CellChat: actual mixed-library environment

The native CellChat analysis used R 4.6.1 on 64-bit Windows, CellChat 2.2.0.9001, and this ordered library stack:

1. `work/repro_v3_cellchat/rlibrary`: 42 newly installed packages, including CellChat.
2. `work/repro_decontx/rlibrary`: inherited analysis dependencies.
3. `work/r_runtime/library`: the R runtime and its supplied packages.

The effective analysis environment contains **287 packages**: 245 inherited/runtime packages and 42 additions. No inherited package version changed. All 245 inherited DESCRIPTION files are byte-identical to the earlier baseline capture. The separate `renv` 1.2.4 library is used only to capture the lock and is absent from the production model library stack.

## Exact records

- [package_lock.tsv](package_lock.tsv): one row per effective or capture-only package, with version, library role, build, repository, commit and DESCRIPTION SHA-256.
- [renv.lock](renv.lock): generated by `renv::lockfile_create(type="all")`; **274 nonbase entries**, including the capture-only renv package. All recorded versions match installed DESCRIPTION fields.
- [R_analysis_sessionInfo.txt](R_analysis_sessionInfo.txt), [R_loaded_namespaces.tsv](R_loaded_namespaces.tsv), [capture_audit.json](capture_audit.json): actual R platform, namespace versions and library precedence.
- [R_package_descriptions.json](R_package_descriptions.json) and `R_DESCRIPTION/`: complete source-backed installed metadata, including remote commits and system requirements where declared.
- [offline_binary_manifest.tsv](offline_binary_manifest.tsv): the original 42 Windows ZIPs, with exact URLs, versions, sizes, SHA-256 and MD5. Their combined size is 62,131,994 bytes.
- [environment_lock_audit.json](environment_lock_audit.json), [environment_manifest.json](environment_manifest.json): verification and release index. The latter excludes itself to avoid a circular hash.
- [provenance/installed_package_verified.json](provenance/installed_package_verified.json): prior native-package verification of 47 function bodies/formals and the entire mouse database against the official fixed source.

CellChat was obtained as a third-party R-universe Windows binary from `blaserlab.r-universe.dev`, with installed `RemoteSha` **75253cd0c9e68410e6e721a6d3a0419a1d7e358f** referring to `jinworks/CellChat`. This is an actual native-package analysis. The LIANA 1.10.0 full pipeline and the fixed-commit LIANA aggregation-only replay remain the distinct analyses described in [the baseline environment report](../repro_v3_environment/report.md).

## Offline Windows overlay restore

The separate `cellchat_environment_windows_R461.zip` archive contains `environment/` metadata and `binaries/` with the exact 42 ZIPs. It contains neither an R runtime nor the 245 inherited/runtime packages. The binary archive is a release/Zenodo asset, excluded from the Git repository.

Use R 4.6.1 with a separately restored baseline matching [the baseline environment](../repro_v3_environment/report.md). Extract the environment archive, then run the following commands, substituting local paths. The target library must not already exist.

```powershell
python BUNDLE/environment/verify_bundle.py BUNDLE
Rscript --vanilla BUNDLE/environment/restore_offline_overlay.R BUNDLE BASELINE_R_LIBRARY NEW_CELLCHAT_LIBRARY
```

The Python command verifies every metadata hash and every binary hash/ZIP CRC. The R command checks the inherited package versions before installation, verifies the binary MD5 values, installs the 42 ZIPs into the new library without network access, checks all 287 effective versions, and loads the native CellChat namespace from that new library. It writes a session record and audit beside the new library. It does not fit a model.

This exact offline overlay workflow **passed on 11 September 2026** in a new isolated library: all 42 binary installations, all 287 effective versions and the native CellChat namespace/commit check passed. See [offline_restore_smoke_audit.json](offline_restore_smoke_audit.json), [offline_restore_smoke_sessionInfo.txt](offline_restore_smoke_sessionInfo.txt) and [offline_restore_execution.json](offline_restore_execution.json). The test used the existing, version-matching baseline; it did not rebuild the baseline or rerun a model. The final archive adds these test records to the metadata; the 42 binary payload hashes are unchanged from the archive used for the test.

The combined renv lock is a source/version record, not proof of a complete fresh source restoration. Some R-universe DESCRIPTION records name `RemoteRef: HEAD` while also recording a commit, and repository packages may change build artifacts without changing their version. The archived ZIP hashes, rather than a future repository download of the same version number, identify the exact overlay artifacts used here. A full restoration of all inherited dependencies from an empty machine has not been tested.

## Re-capture and archive commands

The independent Python review additionally reads RDS files with `rdata` 1.1.0. This package was already pinned in the baseline Python lock; a new capture confirmed **109 current pins, no package additions/removals/version changes**, and complete lock coverage for all five third-party script imports and their 62 active transitive dependencies. See [python_current_audit.json](python_current_audit.json), [python_dependency_closure.json](python_dependency_closure.json) and [requirements-python-current.lock.txt](requirements-python-current.lock.txt). The [delta file](requirements-python-audit-delta.txt) explicitly records that the delta is empty. [requirements-python-optional-audit.txt](requirements-python-optional-audit.txt) separately exposes the `rdata==1.1.0` pin for the optional cross-language review.

For an already matching baseline environment, the explicit optional dependency can be installed without dependency updates, then the audit can be run with its required input files present:

```powershell
python -m pip install --no-deps -r work/repro_v3_cellchat_environment/requirements-python-optional-audit.txt
python work/repro_v3_cellchat_independent_review.py
```

Dependency verification imported the actual modules and checked every active requirement against installed versions and the lock; it did not fit a model or build a fresh Python environment. The binary archive contains R packages only, not Python wheels or the raw input matrices required by the independent audit.

From an analysis checkout with the original libraries and downloads present:

```powershell
Rscript --vanilla work/repro_v3_cellchat_environment/capture_environment.R CHECKOUT_ROOT
python work/repro_v3_cellchat_environment/capture_python_audit.py
python work/repro_v3_cellchat_environment/build_environment_manifest.py
python work/repro_v3_cellchat_environment/build_environment_manifest.py --archive
```

These commands capture metadata and create a separate archive under `work/repro_v3_release_assets/`; they do not install packages or run a scientific model. Installed library directories, restored test libraries, binaries and runtimes are excluded from the metadata manifest. All metadata paths in the manifest are relative. Absolute paths retained in session records document the original execution host.
