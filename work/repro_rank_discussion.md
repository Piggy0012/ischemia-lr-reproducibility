本研究将表达组合的跨队列一致性与相对优先级分数的一致性分开评估，并进一步发现后者对可定位的软件实现细节敏感。LIANA 1.10.0 的 magnitude_rank 是对各评分名次实施 robust rank aggregation（RRA）得到的聚合分数，并非简单百分位名次；其 1−magnitude_rank 也不是通讯强度或动物间疾病检验的 P 值。在本版本默认实现中，Connectome 与 NATMI 共用的 expr_prod 列在方法循环内被连续进行两次降序排名，第二次操作反转了第一次的名次方向，而去重取列发生在该循环之后。四行数值例复现了这一行为；对全部 22 个文库重新计算完整网络后，原目标评分和原生共识均逐值复现。随后仅将每个独特 magnitude 评分列排名一次，保持全网络行、表达评分、资源和筛选参数相同，两种细胞选择的跨队列相关由原生 ρ=0.228/0.102 提高至诊断变体的 0.519/0.514。这个对相同输入进行的明确实现干预，为原生低一致性受到版本行为影响提供直接计算证据；因此，原生结果不能被概括为配体—受体排序方法的普遍局限。该诊断变体仍需以明确名称保留，不能作为经官方发布或生物学验证的“正确共识”替代原结果。

排序阶段的候选集合提供了另一项可检验的上下文因素。原网络的候选数量与细胞类型组成在文库间不同；将所有 11 个文库共有、评分完整的全网络有向边固定为 7,675 条和 7,109 条，并在此集合内对独特评分列各排名一次后，再提取原先固定的 187/174 条目标边，ρ进一步达到 0.645/0.555。这一干预只改变排名候选母集，未重新计算上游细胞类型表达评分。然而，排序聚合分数同时出现更多饱和值：在至少一个队列中疾病效应为零的目标边由原生的 10/8 条，经唯一列诊断的 19/16 条，增至固定全局集合下的 64/59 条。这些零疾病效应均可追溯到对应队列所有动物的 RRA 分数等于 1，即 1−RRA 的优先级等于 0，并不表示没有配体或受体表达。固定全局集合下，非零候选的同向比例为 81.3%/73.0%，但以全部固定候选为分母仅为 53.5%/48.3%。因此，相关提高和条件性同向比例提高必须与方向可判候选减少同时报告，不能仅用排除零效应后的比例宣称可复现性得到全面恢复。

上述干预尚未隔离细胞组成及上游评分背景的全部影响。即使排名候选母集固定，文库内参与计算的细胞类型、各类型细胞数量与表达分布仍可不同，既有 SingleCellSignalR 等评分也继续保留原背景信息。方法数量亦不等于独立证据数量：Connectome 与 NATMI 使用同一表达乘积；expr_prod 与 lrscore 的完整网络名次虽非逐项完全相同，其 Spearman 相关均超过 0.9999999998，最大平均并列名次差仅 3 位，表现为近乎单调的冗余。因而，这一案例的实践价值在于要求将细胞选择、表达资格、软件版本、排名母集、评分饱和及方向分母逐层记录，以区分可重复的表达变化与依赖实现和上下文的候选优先级。它为后续更大队列的算法评估提供可复核的测试案例，而非已经完成细胞特异性通讯或屏障调控机制的验证。
