# Revision figure plan

The main question is whether between-cohort disease effects preserve their concordance when expression summaries become relative ligand–receptor priorities. All main comparisons must use common candidates, both direction denominators, and actual animal replicates. Plotting is descriptive unless a specific archived null test is cited.

Figure 1 retains individual animal target-cell counts and the original marker audit, adding a white separator after Kdr and explicit target-lineage/myeloid group labels. This answers request 12 without concealing the original contamination concern.

Figure 2 uses two effect scatterplots on the same 187 primary candidates, a matched summary across 187/174 candidates, and exhaustive label-null distributions. Dot-and-reference-interval plots are preferable to a pair of 80% versus 58% bars because they expose the null baseline, zero-effect denominator and correlated methods. Reference intervals are permutation quantiles, not confidence intervals. An ECDF is a reasonable alternative to the chosen histogram when the discreteness of 200 assignments dominates.

Figure 3 will compare native scores with fixed-candidate percentile reranking, together with the recorded network size and ties, to distinguish observable ranking behavior from explanations requiring further experiments. Figure 4 will show actual DecontX sensitivity using per-animal points and candidate eligibility. No estimated contamination fraction is treated as measured ambient RNA ground truth.

The previous spatial maps are reduced to one supplementary figure, and have no role in main hypothesis support. Sorted data are shown with paired-pool effect estimates and unadjusted confidence intervals, retaining all original tests in the archive.

Use general journal settings, 7.2 inch width, Arial, 7–9 point labels, Okabe–Ito colors with shape/line redundancy. Preview PNGs and inspect before PDF/SVG export. Every numerical panel has a source table.
