# Computational revision plan

The initial amendment was recorded before inspecting the new annotation and LIANA outputs. It is a post-public-data-exploration revision, not a prospective registration. The original results are retained for comparison. Subsequent explicitly recorded adjustment: the reference-only aggregation was added after the first library showed annotation discrepancies, before inspecting any revised disease contrasts; it is an exploratory sensitivity. The confidence cutoff of 0.5 was specified before that first-library result. No amendment is presented as a public preregistration.

## Independent cell identity and doublets

Apply an official, independently trained mouse brain CellTypist model to all QC-passing cells in each deposited animal library, using log1p(CP10k) normalized over all genes. Do not train on the existing rule labels or use disease effects to assign cell type. Use the whole-brain reference as the primary external identity audit and the cortex/hippocampus reference as a reference-domain sensitivity. This choice was made after inspecting model labels and before predictions: the whole-brain reference includes monocytes and lymphoid cells absent from the smaller model. Record model origin, hash, labels, overlapping genes and predictive confidence. Reference agreement is an annotation sensitivity, not experimental validation; healthy references may misclassify injury states. Match official CellTypist predictions to fixed-coefficient calculations on a deterministic cell subset because the archived models were serialized with an older scikit-learn version.

Run the established Scrublet implementation separately on each complete QC-passing animal library, before target-cell subsetting, with fixed random seed 20260910 and expected doublet rate 0.05. Save observed and simulated scores, automatic threshold and sample/lineage removal counts. Inspect score distributions; do not tune thresholds to preserve any candidate. Scrublet does not eliminate ambient RNA. Submitted filtered matrices cannot support a claim of ambient correction based on empty droplets.

Reaggregate raw counts and ligand/receptor expression for three added sensitivities: original rule labels minus predicted doublets; original target labels supported by the external reference minus predicted doublets; and reference-only target labels minus predicted doublets. Reference-supported selections require a one-versus-rest maximum sigmoid score of at least 0.5; this is a confidence filter, not a calibrated error-rate guarantee. The reference-only selection is included to audit targets missed by the original rules, and is not treated as ground-truth cell identity. Keep sample-level inference and all failed candidates. Inspect cells newly assigned as targets by the independent reference as a potential false-negative audit.

## Established communication-method comparison

Run the actual LIANA software with its supported ligand-receptor methods on each biological sample, using the frozen mouseconsensus interaction resource. Retain other broad cell classes as expression context when computing specificity and explicitly restrict reported directions to astrocyte to endothelial and the reverse. No pooled-cell permutation P value is treated as animal-level disease evidence.

Evaluate the original and identity/doublet-filtered target definitions. Save all method scores, eligibility and consensus ranks. Disease contrasts use per-animal scores and whole-animal label permutations. Report the evaluated denominator, shared-component dependence and method/resource overlap. Agreement across algorithms applied to the same data is methodological robustness, not an additional independent cohort. Keep all four previous examples regardless of their new result; report rank deterioration and loss of eligibility.

Technical amendment before examining any LIANA disease contrasts: use the software default `return_all_lrs=False` to export expression-eligible interactions only. An initial API check with `True` showed that aggregate output did not retain an eligibility flag and assigned worst scores to ineligible rows. These rows must not be mistaken for measured zeros. The final run was restarted with `False`; disease comparisons require a complete observed score for every animal within each cohort. Save per-sample eligibility for fixed examples, including absence. This amendment and the complete-case rule are exploratory implementation decisions, not a preregistered plan. Compute the full eligible cell-type pair network because upstream pair restriction changes the expression context and NATMI denominators.

## Revision decisions

Do not add significance by treating cells as biological replicates, by selectively changing the testing universe, or by replacing a failed example with a successful result without disclosure. Reassess the narrative after the new results. If biological identity or candidate direction fails, qualify or remove the affected biological claim and retain the audit. Recheck differences from closely related published studies. Deliver revised manuscript, new quantitative figures/tables, full code and an explicit change record.
