# CellChat受控资源扩展：独立数值复核

复核日期：2026-09-11。复核读取原生数据库、11库已保存LIANA全网络和缓存、小规模pilot导出及分析代码；没有重跑模型，没有修改CellChat模型目录、运行中的R/Python脚本或发布仓库。数值证据和输入SHA256见同名JSON；独立检查代码为`repro_v3_cellchat_independent_review.py`。

## 总体判断

canonical LR映射、全网络交集和32条目标集符合预定的严格完整亚基定义；抽查的归一化与原LIANA float32运算逐值一致。病例—对照效应、方向分母和相关系数公式适用于当前描述性比较。本次发现的LIANA重RRA精度不一致已在最终汇总前修正；零强度对应的衍生排名现象需要单独报告，分析代理已加入相应审计。这些结论不代表11库CellChat最终模型及全部导出已经由本次复核验收。

## 资源与候选集独立重建

从原生CellChat interaction/complex/cofactor表重新展开完整亚基、去除空项并规范排序，再与mouseconsensus及11库基因覆盖取交集，独立得到1,548条唯一原生LR记录，与受控资源完全一致。重新读取11个原LIANA全网络，仅保留这一资源的有限、完整组件分数后，所得共同有向celltype–LR集合正好为1,222条，目标细胞方向为32条。

原187条主分析目标中，32条具有完全相同的原生CellChat LR亚基定义；这些32条全部保留到最终全网络交集，额外损失为0。其余155条缺少该严格定义下的原生LR组合。保留率为17.1%，体现资源定义的选择范围。32条中星形→内皮8条、内皮→星形24条；去除细胞方向重复后为29种LR组合。不得把资源排除等同于CellChat预测失败，或把当前分母推广为原187条的全部结果。

32条目标仅1条带原生cofactor、31条不带。因此cofactor分层可保留为描述性记录，现有子组规模不足以支持“辅因子导致方法差异”的实证拆解。共同资源也使用相同样本及部分共享先验；原生软件独立运行与独立生物学证据是不同属性。

## 归一化、行列对应与数值导出

代码顺序与原LIANA一致：使用全部提交基因UMI总和作分母，整数计数转float32，乘float32的`10000/total`，再做float32 `log1p`，最后无损提升到R double。提前选取信号基因不会改变逐元素运算或分母；原`load_sample`还检查合并重复symbol后的全基因总和与记录UMI相同。

本复核从最大pilot GSM7841720保留细胞顺序中均匀抽取40个原始缓存稀疏行，独立重构全部865个信号基因，检查每个抽查细胞的全基因总和、barcode位置和归一化结果。34,600个位置与提交给R的Matrix Market导出逐值相同，最大绝对误差为0。整个pilot导出的所有正值也都能以float32→float64精确往返。这是40细胞的独立原始计数抽查，不是全部11库每个细胞的重新计算。

原`write.table`即使设置`digits=17`仍使pilot 2,684个strength值发生末位舍入，最大差异约`5.0e-16`。分析代理保留原TSV/RDS与原hash，从RDS经`sprintf('%.17g')`字符导出生成新的lossless文件，并在R端进行逐值`identical`校验。本复核另外使用Python `rdata`直接读取同一个RDS，按R列优先顺序展平15×15×1,548网络；348,300个prob和P值均与`float_precision='round_trip'`读取的新TSV位级相同。新旧文件及源RDS的hash关系也通过核对。该修复只改变导出精度，没有拟合新的模型或筛掉任何行。

## 排名公式与精度修复

CellChat衍生priority定义为`(ascending_average_rank(strength)-1)/(N-1)`，N固定为1,222。值越大表示相对强度越高；与降序平均rank的互补尺度等价。它是分析者构造的强度百分位，并非CellChat原生共识排名。LIANA比较在同一完整网络上用三个唯一分数列重新计算RRA，再取`1-RRA`；没有挪用另一母集下的原生排名。RRA与经验百分位是不同变换，完整保留其定义比把两者称为同一种rank更准确。

最初汇总代码把TSV读出的float64组件直接送入LIANA RRA，缺少既有重放规范中的float32恢复。独立比较发现11库共有8,918个网络值、210个目标库值发生末位差异，最大绝对差异为`1.2284e-7`。在当前32目标上，两种精度的方向计数和rho恰好相同：同向13/32，双侧非零13/19，rho=0.4507519。分析代理已在汇总尚未运行时加入组件float32恢复，CellChat native strength仍保留float64。修复依据是预定来源精度，而非按哪个结果更显著选择参数。三个唯一列也不等于三项独立生物学验证，表达乘积与LR score仍有近单调冗余。

## 零值、效应与解释边界

原生零strength保留在完整网络中，内部cell-label bootstrap P没有用于筛选或疾病推断。每队列按动物库等权计算MCAO均值减Sham均值，使用既有`abs(effect)<=1e-12`规则标记零效应；同向计数要求两个队列均非零，分别报告全32条和双侧非零分母。代码对常数向量或不足两个候选的rho保留缺失值，而不造出相关系数。n=2的外部缺血组仍然是n=2，新框架不继承原A/B/C家族P值。

平均rank对零strength有一个值得明确展示的背景效应：若固定N中的零值数量为z，所有零值的衍生priority为`(z-1)/(2(N-1))`，通常大于0。pilot有425/1,222条零strength，零值的priority为0.173628。即便一个目标在11库strength始终为0，其他边的零值比例变化仍可能造成它的percentile疾病效应不为0。这个现象属于相对排名背景变化，不能作为该目标存在或复现通讯的证据。分析代理已增加逐目标的全11库零强度标志、各队列零计数、直接/衍生效应及每库零rank下限；最终结果应检查这些表，即使相关目标数量为0也应明确记录。

## 最终汇总前的核验要求

本报告不替代模型完成审计。最终应确认11库各自的模型完成记录、RDS hash、lossless导出位级校验及同一1,222/32集合全部通过；汇总输入hash最好包括固定keys、样本manifest、LIANA组件、custom均值、受控资源和各库model/lossless审计，输出也给出hash。分析代理已获知此建议。完成后仍应把研究定位为这个受控资源、细胞选择及模型配置下的病例研究，不能由32条的描述性结果宣布一般通讯框架benchmark或胶质血管机制。
