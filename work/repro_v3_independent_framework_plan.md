# Independent CellChat extension: frozen initial plan

Frozen before dependency installation and biological scoring: 2026-09-11. This extension is exploratory. Its statistics are not the previously frozen LIANA permutation tests, and it does not establish a broad benchmark or confer submission readiness.

## Choice and provenance

Use the complete native **CellChat R package**, development version **2.2.0.9001**, official upstream commit `75253cd0c9e68410e6e721a6d3a0419a1d7e358f`. The Windows R 4.6.1 x86_64 binary is available from the r-universe builder at `https://blaserlab.r-universe.dev/bin/windows/contrib/4.6/CellChat_2.2.0.9001.zip`. Its build metadata names `https://github.com/jinworks/CellChat` and the same RemoteSha. This is a third-party reproducible build of the official source, not an author-issued binary; preserve the build record, download URL and SHA256, and verify the installed core function bodies/formals and complete mouse DB against the pinned official source. Do not use LIANA's CellChat reimplementation. Do not use manually sourced functions for biological results.

CellPhoneDB v5 is a feasible alternative implementation but its official database requires HUMAN identifiers. Converting these mouse cohorts would add orthology decisions and coverage loss. Moreover, the existing LIANA aggregate already includes the CellPhoneDB expression mean score. CellChat was absent from the existing five-method aggregate and offers an independently executed model with complex subunits and cofactors. Independence of implementation does **not** mean independent evidence or disjoint prior knowledge: LIANA's consensus resource incorporates CellChat and CellPhoneDB resources. [CellPhoneDB official documentation](https://cellphonedb.readthedocs.io/en/stable/RESULTS-DOCUMENTATION.html), [LIANA prior knowledge](https://liana-py.readthedocs.io/en/stable/notebooks/prior_knowledge.html), [CellChat official source](https://github.com/jinworks/CellChat/tree/75253cd0c9e68410e6e721a6d3a0419a1d7e358f).

## Measured feasibility, before installation

The existing analysis Python is 3.12.14 with LIANA 1.10.0, NumPy 2.3.5 and pandas 2.3.3; CellPhoneDB is absent. R is 4.6.1, with Matrix 1.7-5, future, ComplexHeatmap and other dependencies already available. CellChat is absent. Seven direct and 41 total missing dependencies have CRAN Windows 4.6 binaries; their observed Content-Length totals 56,405,669 bytes. CellChat's public package endpoint returned HTTP 200 and 5,726,325 bytes, for approximately 62.1 MB combined compressed downloads. No Rtools installation is needed for this binary route. Install additions only under `work/repro_v3_cellchat/rlibrary`; existing libraries are read-only dependencies.

The official native mouse database contains 3,379 interaction rows. Excluding non-protein signaling leaves 2,377 rows representing 2,365 distinct canonical ligand/receptor pairs; 577 rows include a cofactor. Canonicalization expands complete complex subunits and sorts gene symbols, without mouse-human mapping. Exactly 1,551 protein pairs overlap the archived 3,989-pair mouseconsensus resource. Requiring every ligand, receptor and referenced cofactor gene to be represented in all 11 original matrices, and unambiguous mapping to one native CellChat row, leaves **1,548 rows** (1,011 without cofactors). These are gene-coverage counts, not expression-qualified or significant interactions.

Maximum original context is GSM7841720: 10,135 cells with 1,226 available native protein-signaling genes. A double dense signal matrix is 99,404,080 bytes; four such matrices plus 100 bootstrap cluster-mean arrays are about 412 MB, excluding R package baseline and sparse input. CellChat's official routine converts signaling input to dense, so full-gene dense input is forbidden. These are allocation estimates, not measured peak memory. First run the largest context library; monitor actual process RSS and stop if it exceeds 2 GiB. Continue sequentially only after a successful, tractable pilot.

A bounded source-engine toy using the official tagged v2.1.2 code passed on 20 genes, 120 synthetic cells and six complex/cofactor interactions, with identical scores on repeated seeds (0.82 s for two calls). This is not validation of an installed production package. The current-source toy initially stopped because `collapse` is absent. Repeat the toy through the complete installed 2.2.0.9001 package before biological analysis.

## Primary controlled-resource arm

1. Retain the existing 11 library units: GSE174574, three Sham and three MCAO; GSE245386, three Sham and two MCAO. Use existing raw-count primary QC, frozen cell labels and full context cell types with at least 30 cells. No third cohort, reference-selected or DecontX-corrected cells enter this extension.
2. Use exactly the 1,548 unambiguous shared, gene-covered CellChat interactions. Preserve their native complex and cofactor definitions. Save both native interaction IDs and canonical subunit keys. This holds the LR catalogue fixed; cofactor modeling remains a model distinction and will be marked in the outputs.
3. Normalize each retained cell with its original **all submitted genes** UMI total: `log1p(10000 * count / total)`. Reproduce the existing LIANA float32 normalization operations exactly, then losslessly promote those values to R's float64 storage. Export only relevant signaling genes after normalization; preserve exact barcode alignment, positive sparse entries and original denominators. R model arithmetic remains float64; the input expression values match the original LIANA pipeline.
4. Create one genuine `CellChat` object per library. Set its DB to the controlled catalogue, run `subsetData`, then invoke the installed `computeCommunProb` with explicit `LR.use = controlled_DB$interaction`, `type='triMean'`, `raw.use=TRUE`, `population.size=FALSE`, `nboot=100`, `seed.use=20260911`, `Kh=0.5`, `n=1`, RNA datatype, and sequential future execution. No PPI projection or spatial distances are used. The explicit `LR.use` freezes the tested catalogue and bypasses per-library overexpressed-gene LR preselection; this is a documented controlled configuration, not the default end-to-end CellChat workflow. No disease labels are used during scoring.
5. Save the complete source × target × LR `net$prob` and `net$pval`, including genuine zero scores. Do not use `subsetCommunication` to discard nonsignificant or zero entries. Preserve log-normalization, input hashes, matrix dimensions, context counts, model parameters, timings, package/build identity, and memory telemetry. Library-internal cell-label P values are specificity annotations, not animal-level disease tests.

The model uses group trimeans, geometric aggregation of complex subunits, Hill-type ligand/receptor strength and native cofactor modulation. The routine additionally divides signaling expression by its per-library maximum. This scaling, the trimean's zero behavior and cofactors can affect between-library changes. The native output is an inferred **communication strength** called probability by the package; it is not a calibrated probability of biological communication. [Pinned modeling code](https://github.com/jinworks/CellChat/blob/75253cd0c9e68410e6e721a6d3a0419a1d7e358f/R/modeling.R), [official tutorial](https://github.com/jinworks/CellChat/blob/75253cd0c9e68410e6e721a6d3a0419a1d7e358f/tutorial/CellChat-vignette.Rmd).

## Rank and cross-cohort comparison definitions

CellChat does not return a LIANA-style consensus LR ranking. A descending empirical percentile of its saved strength is an **analyst-derived strength rank**, never an original CellChat consensus score. Keep direct strength and this rank as separate outcomes. `rankNet` is unsuitable as a substitute because its default summaries concern pathway/network information flow.

Construct a fixed full-network key set that is represented in every one of the 11 CellChat outputs and in all 11 archived LIANA full networks for the shared LR resource. Require complete cached LIANA component scores and record the resulting context-pair/LR denominator before any disease comparison. On this exact set, recompute percentile ranks from CellChat strength and, if comparing a LIANA consensus, recompute the documented unique-column RRA from its archived component scores; do not reuse LIANA ranks computed on a different network. Keep average ties and genuine zeros explicit. This controls the eligible rank universe but conditions the estimate on LIANA's detection eligibility; report attrition and do not treat excluded interactions as failed CellChat predictions.

After network ranking, restrict to Astrocyte→Endothelial and the reverse direction. Obtain custom expression coavailability from the corresponding cached mean/detection tables using the original formula, but only on exactly those same complete target keys. Within each cohort compute MCAO mean minus Sham mean separately for custom expression, native CellChat strength, derived strength priority and the matched-universe LIANA diagnostic. Report Spearman rho, concordant nonzero direction counts, zero-effect counts and the complete denominator separately. Use the existing 1e-12 numerical effect-zero convention, with an explicit count of affected ties. Never compare percentages with different candidate denominators as though they shared an estimand.

All new cohort contrasts are descriptive. Do not transfer the original A/B/C permutation P values to this framework; any new inferential test needs its own frozen design and complete label recomputation. The n=2 external disease group remains n=2. Independent software cannot repair biological replication or prove a glial vascular mechanism.
