The create command is supplied for readers and remains untested here. No original runtime, local `.pth` link, machine-only artifact dependency or test-library binary is committed. Version pins and source metadata do not establish binary-identical restoration across platforms. R-universe source/build metadata are retained rather than being described as an unverified CRAN-only installation.

## Independent CellChat environment

The [CellChat environment report](work/repro_v3_cellchat_environment/report.md) and [combined renv.lock](work/repro_v3_cellchat_environment/renv.lock) capture the actual R 4.6.1 library stack: 287 effective scientific packages, including 245 unchanged inherited packages and a 42-package overlay. CellChat 2.2.0.9001 is pinned to official source commit `75253cd0c9e68410e6e721a6d3a0419a1d7e358f`. The exact Windows overlay binaries were restored into a fresh isolated directory and all effective package versions and native namespace were checked. Rebuilding the entire inherited scientific stack from an empty machine remains untested.

The code repository contains lockfiles, package source records, hashes and restoration instructions. The approximately 63 MB Windows binary overlay is a separate release asset, identified by its own manifest and SHA256; installed library trees are excluded. The [CellChat run guide](work/repro_v3_cellchat/README.md) distinguishes native inference, lossless export and descriptive cached comparisons.
