# Descriptive rank-mechanism audit

Revision-stage amendment, 2026-09-11 UTC. The exhaustive null analysis is already complete and remains unchanged. Before this plan, source inspection and a four-row diagnostic established that the installed LIANA 1.10.0 implementation transforms the shared expr_prod column twice because Connectome and NATMI both use it; the second descending rank operation reverses the first. The audit below formalizes that already-observed software behavior alongside the requested descriptive analysis. It is not a prospective claim about discovering the implementation behavior.

1. Reuse exactly the 187 primary and 174 reference_singlet directed edges from the completed fixed-common-universe analysis, with all 11 animals observed in all metrics. For each animal, rank each of custom_score, lr_means, expr_prod, and lrscore over this same universe using ascending average-tie percentile ranks, so larger means higher within-universe priority. Recompute MCAO–Sham mean differences and their cross-cohort concordance. Compare the native expression metric, its fixed-universe percentile representation, and the saved native LIANA magnitude_priority = 1 − magnitude_rank. Report all and nonzero direction denominators and Spearman rho, with absolute effects ≤1e-12 treated as zero. No new P values or selected favorable metrics.

2. Fixed-universe percentile transforms do not rerun rank_aggregate, do not recover its whole-network rank universe, and do not isolate the effect of network composition or the robust rank aggregation function. Their contrast is descriptive, not a causal decomposition.

3. Extract actual eligible full-network row counts and cell-type context counts from each original LIANA JSON audit, and target-direction row counts from its exported TSV. Summarize the ranges by study and selection and retain every animal/context cell count. Count exact ties, largest tie groups, rank=1 (priority=0) fractions, rank=0 (priority=1) fractions, and the observed score range separately in (a) all reported target-direction rows and (b) the fixed complete-case subset. Do not describe target-direction distributions as whole-network distributions; full-network scores were not saved in the original exports.

4. Quantify zero disease effects and edges at native rank=1 in all animals separately for each study/selection, using fixed-universe edges. Display native rank=1 cell-library fractions and comparison statistics as figure source data.

5. Reproduce the four-row implementation diagnostic by directly loading the installed official _rank_aggregate function and deriving its default magnitude specifications from the installed method metadata. Preserve native behavior, then compare an explicitly diagnostic specification that ranks each distinct score column once. This does not patch the package or replace saved native scores. Save source hashes, the exact specifications, four-row inputs/intermediate ranks/RRA outputs, and a pointer to the tagged official upstream source. Its relevance to real whole-network results requires a separately authorized full-network recomputation; no quantitative attribution of the existing concordance drop to this implementation detail is made here.

All outputs use the rank_* prefix. Original computations and null_* outputs remain untouched.
